# Drác App

Aplicativo Flutter para os cuidados do Drác, com SQLite local e compartilhamento entre duas contas usando Firebase Spark.

- [Configuração, comandos e teste nos dois celulares](CONFIGURACAO_FIREBASE.md)
- [Arquitetura, banco, segurança e alterações](ARQUITETURA_COMPARTILHAMENTO.md)
- [Resultados de verificação](VERIFICACAO.md)

Sem Cloud Functions e sem necessidade de Blaze. O código servidor antigo está isolado em functions/legacy e não faz parte da publicação.
